Export to a server

Copies the database into a new one: missing (it's created), or empty. One that already has tables is refused, so nothing is overwritten. If anything fails, the target is put back as it was. It runs as a job, on the pod that runs the jobs (the backend, or the worker), which has to reach the server: add it to the chart's networkPolicy.backend.extraEgress (the worker has the backend's).
