Historical Import

The archive's spreadsheets and pages, downloaded by the app itself. A refresh keeps each source's content when it changed; an import reads each source's latest copy, so a sheet that went private still imports from its last one.

Import runs a preview first: it lists what each season would lose, then you apply it.
